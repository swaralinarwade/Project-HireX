01 Executive Summary & System Objectives

HireX is an enterprise talent intelligence platform bridging the structural chasm between university engineering curricula and corporate hiring demands. Traditional placement pipelines suffer from severe resume inflation (over 50% unverifiable claims), reactive university syllabi lagging years behind industry tech stacks, and operational chaos caused by unstructured circulars forwarded via messaging apps.

Core Engineering Mandate
Replace unverified text resumes with cryptographic code proofs, in-browser AST complexity audits, real-time acoustic/gaze proctoring, and explainable multi-signal match vectors to achieve mathematical hiring certainty.

04 Functional Requirements (FR Matrix)

Module 1: Student Command Center & Verified Skill Passport

FR-01.1 (Readiness Calibration): Computes dynamic Placement Readiness (0–100%) weighted by verified code proofs (40%), cognitive aptitude (35%), and academic benchmarks (25%).
FR-01.2 (Company Cutoff Radar): Compares student competencies against real-time company thresholds (e.g. Google, Microsoft, TCS) with exact skill delta readouts.
FR-01.3 (Counterfactual Guidance): Outputs actionable steps: "Completing 1 Distributed Systems AST challenge raises Google match by +14%."

Module 2: Forensic Proctoring & Anti-Cheating Engine

FR-02.1 (Acoustic Anomaly Detection): In-browser Web Audio API samples microphone Root Mean Square (RMS) decibels every 100ms to detect whispering without transmitting raw audio.
FR-02.2 (Gaze & Pose Deflection): Evaluates head pose pitch/yaw angles via offscreen canvas; continuous deviation > 28° for > 3.5s records a gaze strike.
FR-02.3 (Tab Blur & Multi-Window Lock): Hooks document.visibilityState and window blur; 3 tab-switching strikes automatically freeze the assessment.

Module 3: In-Browser DevProof AST Code Lab & Cognitive Arena

FR-03.1 (AST Structural Quality): Parses code syntax trees to compute McCabe Cyclomatic Complexity and Halstead Program Volume, detecting unoptimized loops or AI-copied boilerplate.
FR-03.2 (9-Game Cognitive Agility Arena): Measures working memory, spatial reasoning, and reaction latency evaluated under a logarithmic time-decay model.

Module 4: Recruiter Intelligence & Explainable Matcher

FR-04.1 (Explainable Fit Scoring): Synthesizes TF-IDF cosine similarity, weighted skill set overlap, and verified proof scores into a single transparent fit percentage.
FR-04.2 (Zero-Pedigree Blind Screening): One-click anonymization masking candidate names, colleges, and demographics to eliminate bias.

Module 5: Autonomous Placement Co-Pilot (ReAct Loop)

FR-05.1 (Autonomous 6-Tool ReAct Loop): Implements Thought → Action → Observation → Synthesis utilizing 6 sovereign atomic tools: get_student_profile, check_drive_eligibility, audit_code_submission, match_jobs_for_candidate, recommend_curriculum_upgrades, and generate_action_plan.

06 Algorithmic Formulations & Mathematical Models

Model 1: Sovereign Verhoeff Checksum KYC Engine Abstract Algebra D₅
Σ F(d_i, i) = d(… d(d(0, p(1, d₁)), p(2, d₂))…, p(n, d_n)) = 0

Model 2: Forensic Document Laplacian Variance Tamper Detector Spatial Filtering
∇² I(x, y) = I(x+1, y) + I(x-1, y) + I(x, y+1) + I(x, y-1) - 4I(x, y)
Focus Measure: σ² = Var(∇² I) = (1 / MN) Σ (∇² I(x, y) - μ)²

FitScore = 0.35 · [(v_JD · v_Cand) / (||v_JD|| ||v_Cand||)] + 0.40 · [|S_Cand ∩ S_JD| / |S_JD|] + 0.25 · ProofMultiplier
Replaces unexplainable black-box ATS rejections with mathematically backed candidate ranking with exact missing-skill breakdowns.
Model 4: DevProof AST Complexity Evaluation Graph Theory
McCabe Complexity: V(G) = E - N + 2P
Halstead Program Volume: V_H = (N₁ + N₂) · log&sub2;(η₁ + η₂)

Model 5: Logarithmic Time-Decay Cognitive Agility Engine Neuroscience Analytics
Score_i = [BasePoints × (1 - α · ln(1 + Δt / τ_target))] × Correct - β · (Mistakes)²
